## Install

1. Copy `KuchTohGadbadHai.apk` to your phone (USB, Drive, WhatsApp to yourself, etc.).
2. Tap the file. Android will ask to allow installs from that app/source — allow it.
3. Install and open **Kuch Toh Gadbad Hai**.

The APK is signed with a standard debug key, so it installs on any phone
without Play Store. If you already have another build with the same package
name, uninstall it first.

## Controls

| Action | Touch | Keyboard |
| --- | --- | --- |
| Move | ◀ ▶ buttons | ← → / A D |
| Punch (3-hit combo) | PUNCH | J / Z |
| Jump | JUMP | K / Space / W |
| Special (when meter is full) | ★ | L / X |
| Pause | ❚❚ | P / Esc |

Fill the **Gadbad Meter** by landing hits, then hit ★ for
**"DARWAZA TOD DO!"** — it clears the whole wave.
